# Cover Image Brief

**Message in one look:** a messy bug report goes in, proof comes out.

**Composition:** left third, a cropped GitHub-style issue card with a vague title ("Last item in stock can be sold twice"). Right two thirds, the large trial strip from the dashboard: top row labelled "Before" with a few reproduced cells in the reproduced colour among clean cells; bottom row labelled "After" with a longer row of clean cells. The word "Reprise" set in IBM Plex Sans 600 at the lower right.

**Colours and type:** exactly the dashboard tokens in `02-specs/dashboard.md` (Mist background, Slate ink text, Reproduced, Clean). No gradients, no drop shadows, no robot imagery.

**Production:** build it as an HTML page using the dashboard's CSS and a real record, screenshot at the size required by lablab (gate G-13), then check legibility at thumbnail size.
