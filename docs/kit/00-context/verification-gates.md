# Verification Gates

Each gate is something the design needs but that has not been verified. Phase 0 of the build plan checks all of them before any product code is written. Record the outcome in the "Result" column and, if a gate fails, apply its fallback and update the affected spec.

**Provider amendment (ADR-12).** While the runtime provider is `claude`, the Bob-only gates G-1 to G-7, G-14, G-19 and G-20 are **deferred until the Bob switch**; they must all pass at that checkpoint (before phase 9). G-4's Claude counterpart is the token table in `02-specs/bob-integration.md`, measured in phase 3c. G-21 applies to the Claude provider. Gates G-11, G-12 and G-16 are resolved in the phases named in their "How to check" column.
